# Horse Powered 2.7.5

Animal Trap recipes can now be limited to a dimension.

## Changes

- Trapping recipes take an optional `dimension` field: one dimension ID or a list of them. The trap only catches when it is in one of those dimensions
- JEI and EMI show the dimension on the recipe using its translated name from the `dimension.<namespace>.<path>` lang key, falling back to the ID when no translation exists. Names for the Overworld, the Nether and the End are included. A recipe with several dimensions shows the first one followed by "...", and hovering over that line lists them all
- Jade shows "Wrong dimension" in red when the bait's recipe needs a different dimension
- When several trapping recipes use the same bait, the trap now picks the one whose biome, dimension and water conditions match where it is, using `priority` to break ties. Before, it always took the first recipe for that bait, so a second recipe for the same bait in another biome could never catch anything
