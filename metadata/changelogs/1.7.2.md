# Horse Powered 1.7.2

## Bug Fixes

- Leading an animal near a station that already has a worker no longer stops you putting items in ([#25](https://github.com/breakinblocks/HorsePowered/issues/25)).
- Right-clicking a station whose input slot is full no longer places the item you are holding on top of the station.
- Emptying a station no longer leaves progress behind that stopped it accepting new items.
