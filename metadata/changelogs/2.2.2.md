# Horse Powered 2.2.2

## Bug Fixes

- Hand grindstone now renders the primary and secondary output items on the grinding surface. Processed results were invisible before, making turns appear to do nothing.
- Each hand grindstone turn now plays a grinding sound with slight pitch variation and emits stone particles for clear feedback.
- The input item on the hand grindstone now spins in step with the crank, so each click is visible immediately.

## Improvements

- Chopping blocks (both hand and horse-powered) now display the log standing upright on the surface instead of flat, so the blade cleaves it like a real axe chop.
- Hand chopping block display now matches the scale of the horse chopper and sits properly on the surface instead of floating above it.

## Documentation

- Hand grindstone guide clarifies that sneak + right-click pulls un-milled input back out.
