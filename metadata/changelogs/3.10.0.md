# Horse Powered 3.10.0

## Gameplay Changes

- **Animal Trap optional bait consumption** (issue #14): two new config keys under `[animal_trap]` in `config/horsepowered-common.toml` let pack makers require ongoing feeding for captured animals.
    - `baitConsumed` (default `false`): when `true`, the trap needs matching bait in the bait slot to generate each drop cycle. With the slot empty the drop timer pauses at the threshold until new bait is supplied. Bait can be reinserted (by hand or hopper) while an animal is captured, and the inserted bait must match a trapping recipe whose entity equals the captured animal so a cow trap cannot be fed kelp.
    - `baitConsumeChance` (default `100.00`, range `0.01`-`100.00`): only applies when `baitConsumed` is `true`. Rolled each time drops are generated; on success one bait is consumed. At `100.00` the bait is always consumed; lower values let one bait fuel multiple drop cycles on average.
    - Default behavior is unchanged: with `baitConsumed=false` a captured animal keeps producing drops without further bait, matching the 3.9.x trap behavior.
