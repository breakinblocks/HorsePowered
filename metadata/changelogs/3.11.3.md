# Horse Powered 3.11.3

Lets any tagged worker be leashed, and updates to the latest 26.1.2 builds.

## Bug Fixes

- Mobs added to the `horsepowered:valid_worker` tag can now be leashed with a lead and led to a station, even ones Minecraft normally refuses a lead on, such as villagers.

## Updates

- Updated to NeoForge 26.1.2.109, JEI 29.40.0.102, Jade 26.1.11, and GuideMe 26.1.12-beta.
