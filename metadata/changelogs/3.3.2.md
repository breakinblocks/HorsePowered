# Horse Powered 3.3.2

## Bug Fixes

- JEI now shows grinding, chopping, and pressing recipes again. NeoForge 26.1 stopped auto-syncing custom recipe types to clients, so the JEI plugin registered an empty list and the machine categories appeared empty. The mod now opts in via `OnDatapackSyncEvent#sendRecipes` on the server and captures the client's `RecipeMap` from `RecipesReceivedEvent`, which works on both integrated and dedicated servers.

## Recipe Changes

- Horse Press crafting recipe no longer collides with vanilla Chest; it now requires a Piston in the center (planks border + piston).
