# Horse Powered 3.3.1

## New Content

- **Work Saddle** — new item that captures any creature in the `horsepowered:valid_worker` tag into a portable saddle and releases it when right-clicked on a block. Crafted shapelessly from a saddle and a lead. Shows the carried mob as a small overlay on the saddle icon.
- **Press fluid input** — pressing recipes can now declare an optional `fluidInput` (a `SizedFluidIngredient`) that is drained from the press's internal tank each cycle, in addition to the item input.
- **Press bucket interaction** — right-click the press with a filled bucket to fill the tank, or with an empty bucket to drain it.

## Recipe Changes

- Chopping Block recipe is now shapeless: any log + any wooden slab.

## Bug Fixes

- Horse Press tank no longer keeps rendering its previous fluid on the client after a recipe drains it.
- Worker mob no longer jitters in place while idle on horse-powered blocks.
- Worker walk animation no longer resets mid-cycle while a recipe is processing
- Output items on the Horse Grindstone and Horse Press no longer render outside the block bounds.
- Output slot count now syncs correctly when an existing stack grows (Jade no longer reports a stale "1x" after subsequent grinds/chops/presses).
