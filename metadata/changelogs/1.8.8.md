# Horse Powered 1.8.8

## Changes

- A worker's jump strength now sets how fast it walks on every machine, on top of the floor's path speed. A 0.4 jump strength worker walks at normal speed and a 1.0 horse at 1.6x. The baseline and scale are configurable under `[horse_path]`
- Jump strength overrides in `data/<namespace>/horse_engine_jump_strength/` now work without Create installed and apply to every machine
- Jade shows the worker speed and path speed on machines with a worker attached
- Looking at any mob that can be a worker shows its jump strength, worker speed and, with Create installed, its horse engine output in Jade

## Bug Fixes

- Very fast workers no longer get stuck jittering on a path point
