# Horse Powered 3.1.1

## Bug Fixes
- Fixed an issue where items could fail to stack properly in machine output slots
- Fixed unnecessary network updates when interacting with machines without changing anything
- Client display settings (item counts, look-at requirement, placement highlights) are now per-player instead of being forced by the server

## Improvements
- Improved stability when other mods interact with Horse Powered block entities
- Improved performance with hopper automation on busy servers
- General internal code cleanup and optimization
