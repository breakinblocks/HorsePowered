# Horse Powered 1.3.0

## New Features

- **Recipe tiers**: chopping and grinding recipes accept an optional `"tier"` field (`"any"` | `"hand_only"` | `"horse_only"`, default `"any"`). Hand and horse variants can share the same input ingredient with different yields — e.g. `1 bone -> 2 bonemeal` on the hand grinder alongside `1 bone -> 4 bonemeal` on the horse grinder — without colliding, and recipes can be made exclusive to one power mode.
- **Recipe sort priority**: all recipe types accept an optional `"priority"` integer (default `0`). Higher priority sorts earlier in the JEI/EMI recipe list, so related recipes (e.g. your ores) can be grouped together instead of scattered by load order.
- **EMI compatibility**: native EMI plugin ships alongside the existing JEI integration. Hand and horse machines get their own EMI categories and workstations, and the progress arrow now renders correctly under EMI (previously appeared as a missing-texture swatch under EMI's JEI-compat bridge).
- **Hand vs horse JEI/EMI split**: grinding and chopping now show separate recipe tabs for the hand-powered and horse-powered machines, filtered by recipe tier.

## Bug Fixes

- **Horse chopper break animation**: breaking the upper half of the chopper (the stick/supports) no longer produces a storm of missing-texture particles, and the break progress overlay is now visible across the full 2-block model instead of being invisible on the top half.
- **Hopper automation above the chopper**: vanilla hoppers and chests can now input items into the chopper's input slot from the upper block of the multi-block, letting players route automation above the horse's path instead of on the ground where the horse would try to climb it.
