# Horse Powered 3.11.2

Station interaction fixes.

## Bug Fixes

- Leading an animal near a station that already has a worker no longer stops you putting items in (breakinblocks/HorsePowered#25).
- Right-clicking a station whose input slot is full now hands you the finished output instead of placing the item you are holding on top of the station.
- Emptying a station no longer leaves progress behind that stopped it accepting new items.
