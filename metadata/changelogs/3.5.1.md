# Horse Powered 3.5.1

## Bug Fixes

- Generator now actively pushes FE to adjacent energy handlers
- Generator energy storage is properly persisted on every change and no longer caps extraction at 0 FE/tick
- Working area validation now also checks the floor beneath the walking ring, so the worker can no longer float over missing blocks
- Levers placed in the working area no longer invalidate it, allowing the generator (or any horse-powered station) to be redstone-toggled with a wall lever
