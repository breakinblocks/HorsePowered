# Horse Powered 3.11.6

Press fixes: no more lost items from pipes, and component recipes show in JEI.

## Bug Fixes

- Pipes and other mods that insert several items at once into an empty Press no longer lose items. The Press used to accept the whole transfer, keep only the recipe's input count and delete the rest (breakinblocks/HorsePowered#31)
- Pressing recipes whose ingredient is a `neoforge:components` ingredient (or any other custom ingredient type) worked in the press but were missing from JEI. They now show, with the matching components on the input item (breakinblocks/HorsePowered#30)
- Emptying a filled container on the Press no longer errors when the bottling recipe's container is a custom ingredient, and the empty container handed back keeps its components
