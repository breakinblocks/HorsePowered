# Horse Powered 3.11.11

## Changes

- A worker's jump strength now sets how fast it walks on every machine, on top of the floor's path speed. Most mobs have 0.42 jump strength and walk at normal speed, and a 1.0 horse walks at about 1.6x. The baseline and scale are configurable under `[horse_path]`
- Packs can set a fixed jump strength per mob with the `horsepowered:horse_engine_jump_strength` entity type data map
- Jade shows the worker speed and path speed on machines with a worker attached
- Looking at any mob that can be a worker shows its jump strength and worker speed in Jade

## Bug Fixes

- Very fast workers no longer get stuck jittering on a path point
