# Horse Powered 3.5.0

## New Features

- **Fluid pipe automation for the press**: fluid pipes can now connect to the press (on either half of the multi-block). Insertions route to the input tank, extractions drain only the output tank — pipes can't steal reagents mid-process or contaminate output with the wrong fluid.
- Press now has separate input and output tanks, shown side-by-side in the tank window (input on the left, output on the right).

## Bug Fixes

- Chopping block now accepts logs on right-click instead of placing them as a block above the station
- Stations now drop themselves when broken (chopping_block, chopper, press, grindstone, hand_grindstone, generator)
- Stations break at the correct speed with the proper tool: axe for chopping_block/chopper/press/filler, stone-tier pickaxe for grindstones, iron-tier pickaxe for the generator
- Guarded the horse chopper renderer against the last-frame purple/black flash when the block is broken

## Improvements

- Audio/visual feedback on the chopping block: wood-place sound and oak-log particles when inserting a log, axe-strip sound with pitch variation and particles on each strike
- Hand chopper (chopping block) now displays the log/item being chopped on top of the station
- Hand grinder now displays the item being ground on top of the station
- Horse press input/output items raised to sit on top of the base so the plunger visibly descends onto them
- Jade tooltip now shows input and output fluids separately on the press
