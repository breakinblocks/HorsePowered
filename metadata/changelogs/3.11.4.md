# Horse Powered 3.11.4

Drying Rack, Animal Trap and path floor fixes.

## Bug Fixes

- Breaking any corner of a Drying Rack now removes the whole rack instead of leaving pieces behind (FTBTesting/Testing-Issues#4355)
- Leftover Drying Rack pieces from earlier versions clear themselves when one of them is broken
- Right-clicking an Animal Trap with an empty hand now drops its contents, as the guide describes (FTBTesting/Testing-Issues#4354)
- Dirt paths, and any other block listed in the path speed config, now count as valid floor under the working area instead of marking it obstructed (FTBTesting/Testing-Issues#4322)
