# Horse Powered 1.2.0

## New Features

- **Fluid pipe automation for the press**: fluid pipes can now connect to either half of the multi-block. Insertions go to the input tank, extractions drain only the output tank — pipes can't contaminate the input with arbitrary fluids or steal output mid-process.
- Press now has separate input and output tanks, shown side-by-side in the tank window (input on the left, output on the right).
- Press supports bucket interaction — right-click with a full or empty bucket to fill the input tank or drain the output tank.

## Improvements

- Hand chopper (chopping block) now displays the log/item being chopped on top of the station.
- Hand grinder now displays the item being ground on top of the station.
- Jade tooltip on the press splits fluid display into "Input Fluid" and "Output Fluid" rows.
