# Horse Powered 1.1.0

## Bug Fixes

- Chopping block now accepts logs on right-click instead of placing them as a block above the station
- Stations now drop themselves when broken (chopping_block, chopper, press, grindstone, hand_grindstone)
- Stations break at the correct speed with the proper tool: axe for chopping_block/chopper/press/filler, pickaxe for grindstone/hand_grindstone (stone-tier or better required for the grindstones)
- Fixed a missing-texture particle burst when breaking a chopper, caused by the renderer running one final frame after the block entity was removed

## Improvements

- Added audio/visual feedback on the chopping block: wood-place sound and oak-log particles when inserting a log, axe-strip sound with pitch variation and particles on each strike
